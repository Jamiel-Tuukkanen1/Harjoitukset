Tässä harjoituksessa käyttäjä voi lisätä tuotteita.

Käyttäjä valitsee toiminnon kirjoittamalla numeron.

1 = Listaa tuotteet (ohjelmaa listaa kaikki tuotteet)

2 = Lisää tuote (ohjelma kysyy lisättävän tuotteen nimen)

3 = Poista tuote (Ohjelma poistaa tuotteen valitsemasi numeron avulla, joka merkkaa mikä tuote on kyseessä)

4 = Näytä varaston kokonaisarvo (ohjelma näyttää tuotteiden määrän ja kokonaishinnan)

0 = Lopeta (ohjelma lopettaa)
