Tässä harjoituksessa käyttäjä voi lisätä ostoksia.

käyttäjä valitsee toiminnon kirjoittamalla numeron (1,2,3 tai 4).

1 = Lisää kulu (ohjelma kysyy asian nimen ja kulun hinnan)
2 = Näytä kulut (ohjelma näyttää kaikki kulut)
3 = Näytä tilasto (ohjelma näyttää kaikki kulut yhteensä)
4 = Lopeta sovellus (ohjelma lopetetaan)
