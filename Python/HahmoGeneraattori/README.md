Tässä harjoituksessa ohjelma arpoo hahmon ja arvot sen ominaisuuksille.

ohjelma arpoo ominaisuuksien arvot siten, että kolme kertaa arpoo 1-6 numeroa ja summaa ne.

ominaisuuksia ovat strength, dexterity, constitution, intelligence, wisdom, charisma.
hahmoja ovat Warrior, Wizard, Priest ja Rogue.
rotuja ovat Human, Elf and Dwarf.

käynnistä vain ohjelma ja se arpoo kaikki automaattisesti.
